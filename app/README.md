# Campus Vendors mobile app

Standalone Expo app for Android and iOS. It lives in this directory and does not modify the website source files.

## Run

```sh
npm install
npm start
```

Scan the Expo QR code with Expo Go, or press `a` / `i` to launch an installed simulator. The app currently reads the live directory from the website API at `https://campus-vendors.onrender.com`.

The app uses the website palette: forest green `#16302a`, warm orange `#e2672b`, and cream `#f5f0e6`.
